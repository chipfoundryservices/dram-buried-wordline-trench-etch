# Book 26 — DRAM Buried Word-Line Trench Etch

16 chapters in four parts, Appendices A–G, glossary and index.

- Read: `build/out/book26-dram-buried-wordline-trench-etch.html` or `.epub`
- Rebuild: `python3 build/build.py` (needs `markdown`)
- Re-run the simulation: `cd sim && python3 trench_mc.py` (needs `numpy`, ~10 s)

Transport numbers (Ch. 4–5, App. B) and the silicon/oxide depth histories (Ch. 7) are computed by `sim/trench_mc.py`; process values elsewhere are illustrative.
