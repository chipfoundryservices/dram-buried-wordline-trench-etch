# Appendix D — Illustrative Process Windows

These ranges are representative of published and generic practice, not any manufacturer's recipe.

| Parameter | Main etch | Over-etch / fin |
|---|---|---|
| Pressure | 5–30 mTorr | 5–20 mTorr |
| Source power | 300–1000 W | 200–600 W |
| Bias power | 100–400 W | 50–200 W |
| HBr | 100–300 sccm | 100–200 sccm |
| Cl₂ | 0–50 sccm | 0–20 sccm |
| O₂ | 2–10 sccm | 2–8 sccm |
| NF₃ / CF₄ | 0–10 sccm | 0–20 sccm |
| He / Ar | 0–200 sccm | 0–200 sccm |
| Wafer temperature | 30–60 °C | 30–60 °C |

| Target | Typical |
|---|---|
| Trench CD | 15–25 nm |
| Silicon depth | 120–160 nm |
| Fin height | 10–30 nm |
| Sidewall angle | 87–89.5° |
| Depth 3σ (within wafer) | < 4 nm |
| Fin-height 3σ | < 3 nm |
